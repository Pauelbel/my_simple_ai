# Архитектура

My Simple AI работает на Tauri 2. Веб-интерфейс на Svelte и TypeScript загружается из ресурсов приложения. Rust отвечает за системные окна, единственный экземпляр, файловое хранилище и установку обновлений.

- Tauri-команды принимают относительные пути к заметкам. Сохранение заменяет файл атомарно в его каталоге.
- Заметки хранятся в `Документы/My Simple AI/notes` в UTF-8 Markdown. Данные отделены от пакета приложения.
- Обновления загружает Rust через официальный Tauri Updater. Веб-интерфейс вызывает проверку, загрузку и установку подготовленного обновления.
- Node.js и Rust нужны для разработки и сборки. Запуск `dev-tauri.sh` или `dev-tauri.bat` включает Vite HMR и отслеживание изменений Rust.
- Версии npm и Cargo фиксируются lock-файлами. Готовые пакеты и подписи выпускаются по [спецификации распространения](distribution.md).
