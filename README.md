# Desktop Assistant

Локальный desktop-помощник на Python, PySide6 и QML. Это MVP, который покрывает
первые шесть этапов ТЗ: прозрачная анимированная голова, меню, запись голоса,
локальная транскрибация русской речи, Markdown-заметки, история и настройки.

## Запуск разработчика

```bash
python3.13 -m venv .venv
# Linux
. .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -e .
python scripts/prepare_speech_model.py
python -m desktop_assistant
```

Для разработки рекомендуется Python 3.13. На Windows среду можно создать
командой `py -3.13 -m venv .venv`. `./run.sh` использует проектную `.venv`, если она есть.

## Локальный голосовой ввод

Нажмите сферу или пункт **Голосовой ввод**, продиктуйте текст и нажмите ещё раз.
Приложение распознаёт русский язык через **Faster Whisper Small, CPU INT8**,
копирует результат в буфер обмена и добавляет его в историю.
Пунктуация берётся из распознавания; слова и смысл автоматически не переписываются.
Тишина отсекается локальным Silero VAD. При пустой записи буфер не изменяется.

Модель загружается при первой транскрибации и остаётся в памяти для следующих.
Обработка идёт в фоновом потоке. В настройках можно выбрать число потоков CPU;
скорость зависит от процессора и длины записи. API-ключ не требуется.
Запись — WAV, моно, 16 кГц средствами Qt. Временный файл удаляется после обработки.

`scripts/prepare_speech_model.py` запускается **только разработчиком при подготовке
сборки**: скачивает закреплённую версию модели (около 486 МБ) в
`models/faster-whisper-small` и создаёт манифест контрольных сумм.
Полная поставка содержит модель, токенизатор, Silero VAD и библиотеки.
Приложение загружает только локальные файлы; при их отсутствии сообщает об ошибке,
а не скачивает их. Интернет при первом и последующих запусках не нужен.

Редактирование расшифровки — следующий этап: **Ollama** и
**OpenAI-совместимый API с ключом**. Сейчас эти редакторы не подключены.
Старые API-настройки сохранены в файле настроек, но для распознавания не используются.

Данные по умолчанию находятся в стандартной папке данных приложения ОС
(`AppData/Local/DesktopAssistant` на Windows и `~/.local/share/DesktopAssistant`
на Linux). Заметки хранятся как обычные `.md` файлы в папке `notes`.

## Интерфейс заметок

Три панели на QML: дерево папок и Markdown-файлов, список заметок с поиском
и редактор с режимом просмотра. Ширина панелей меняется перетаскиванием
разделителей. Контекстное меню дерева позволяет создавать, переименовывать,
перемещать и удалять элементы. Непустые папки защищены от удаления.

Кнопка внизу библиотеки переключает светлую и тёмную тему; выбор сохраняется.
Изменения заметки сохраняются при переходе к другому документу и закрытии окна.
Если запись файла не удалась, окно остаётся открытым с вашими правками.

Горячие клавиши: **Ctrl+N** — заметка, **Ctrl+Shift+N** — папка,
**Ctrl+F** — поиск, **Ctrl+S** — сохранить, **Ctrl+E** — просмотр/редактирование,
**Ctrl+B / Ctrl+I** — жирный/курсив в редакторе.

Дизайн-система находится в `desktop_assistant/qml/notes/Theme.qml`;
рядом — общие кнопки, SVG-иконки, поле ввода, панели, дерево и контекстное меню.
`notes_window.py` связывает QML с существующим Markdown-хранилищем.
Дополнительные зависимости для интерфейса не нужны.

Проверка файловых операций и интерфейса без открытия окна на рабочем столе:

```bash
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software python -m unittest discover -s tests -v
```

## Сборка

```bash
pip install -e '.[build]'
python scripts/prepare_speech_model.py
pyinstaller desktop-assistant.spec --noconfirm
```

Собирать нужно отдельно на Fedora и Windows. На целевых компьютерах Python,
Docker и права администратора не требуются.

Результат — папка `dist/DesktopAssistant` со всеми зависимостями и моделью.
Переносить нужно папку целиком. На Linux запускайте `DesktopAssistant`, на Windows —
`DesktopAssistant.exe`. Сборка проверяет контрольные суммы модели и не создаёт
неполный офлайн-дистрибутив. Модель хранится отдельными файлами внутри поставки,
чтобы не распаковывать её заново при каждом запуске.
