# Безопасность

## Модель угроз

Модель учитывает выход за пределы библиотеки, вредоносный Markdown, утечки содержимого заметок, избыточные разрешения и подмену пакетов обновлений.

## Правила frontend

- CSP запрещает внешние scripts, frames и network connections.
- `unsafe-eval` запрещён.
- Внешние CDN, Google Fonts и remote editor assets запрещены.
- Нельзя передавать HTML заметки в `{@html}`.
- `{@html}` допустим только для статического внутреннего набора SVG paths.
- DevTools отключаются в release.

## Tauri commands

- Команда делает одну операцию и проверяет каждый аргумент.
- Frontend не получает generic `readFile`, `writeFile` или `shell.execute`.
- Relative path принимает только normal components и ожидаемое расширение.
- Symlinks не обходятся при обходе notes root.
- Размер входных данных ограничен до выделения больших буферов.
- Ошибка возвращает безопасное сообщение; полный stack остаётся в локальном логе.

## Permissions

- Capabilities привязаны к label окна.
- Главное окно имеет только стандартный набор core-разрешений.
- Новое разрешение требует изменения этой спецификации и threat review.

## Данные и логи

- Текст заметок и распознанная речь не пишутся в diagnostic log.
- API keys не хранятся в JSON; при появлении облачных интеграций используется OS credential store.
- Логи ротируются, общий размер ограничен.
- Crash report остаётся локальным, отправка возможна только opt-in.

## Release

- `package-lock.json` и `Cargo.lock` обязательны.
- CI собирает пакеты после проверки Svelte, формата Rust и Rust-тестов.
- NSIS устанавливается для текущего пользователя.
- Обновление требует подписи Tauri с той же версией, что указана в манифесте. Приложение принимает только более новые версии.
