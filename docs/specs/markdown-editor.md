# Визуальный Markdown-редактор

## Реализация

- Milkdown Crepe — WYSIWYG слой.
- ProseMirror — модель документа и undo/redo.
- CodeMirror feature — редактирование fenced code blocks.
- На диске хранится обычный UTF-8 Markdown.

## Поддерживаемая разметка

- Заголовки H1–H6.
- Bold, italic, strike, inline code.
- Ссылки и локальные изображения.
- Маркированные, нумерованные и task lists.
- Цитаты и horizontal rule.
- Fenced code с language identifier.
- GFM-таблицы без merged cells.

## Код

- Отдельный фон и рамка в обеих темах. В шапке видны язык и кнопка «Копировать».
- Моноширинный системный шрифт: Cascadia Code → Consolas → monospace.
- CodeMirror подсвечивает синтаксис выбранного языка и показывает номера строк. У блока без языка сохраняется оформление обычного кода.
- Tab работает внутри code block.
- Горизонтальная прокрутка не расширяет документ.
- Язык сохраняется после тройных backticks.
- Копируется только текст кода, без номеров строк и Markdown-ограждения.

## Оформление документа

- Ссылки выделены цветом и подчёркиванием в обеих темах.
- Встроенный код, цитаты и заголовки таблиц имеют собственные стили.
- Панель форматирования остаётся над документом во время прокрутки.
- Переключение темы меняет CSS-палитру редактора и подсветку синтаксиса без повторной загрузки документа.

## Сохранение

- Изменение выставляет dirty немедленно.
- `Ctrl+S` сохраняет явно.
- Сохранение считывает актуальный текст редактора, даже если уведомление об изменении ещё не дошло до интерфейса.
- Autosave: debounce 800 ms после внедрения conflict detection.
- Смена заметки сначала сохраняет текущую.
- Запись атомарная; лимит одной заметки 16 МБ.
- При внешнем изменении файла пользователь выбирает reload или сохранить копию.

## Производительность

- До 200 КБ — обновление preview без заметной задержки.
- Свыше 200 КБ — Markdown сериализуется на blur/save, не каждый transaction.
- Список заметок виртуализируется при количестве более 500.

## Ссылки и изображения

- `http`, `https`, `mailto` открываются только после явного действия пользователя.
- Остальные URL schemes блокируются.
- Локальные изображения должны находиться внутри notes root или assets заметки.
- SVG рассматривается как недоверенный контент и не исполняет scripts.
