# Спецификации My Simple AI

Спецификация приложения на Tauri 2.

Документы являются источником требований. Изменение поведения сначала отражается в соответствующей спецификации, затем в коде и acceptance-тестах.

- [Архитектура](architecture.md) — процессы, границы модулей, хранение данных и IPC.
- [Интерфейс](interface.md) — структура меню, дизайн-система и состояния компонентов.
- [Окна и движение](windows-and-motion.md) — окна, переходы, drag/resize и reduced motion.
- [Редактор Markdown](markdown-editor.md) — формат файлов и визуальное редактирование.
- [Безопасность](security.md) — модель угроз, permissions и работа с файлами.
- [Установка и обновления](distribution.md) — форматы пакетов, подпись и публикация.

## Обязательные определения

- **Shell** — минимальная Rust/Tauri-часть, управляющая окнами и системной интеграцией.
- **Frontend** — Svelte-интерфейс внутри системного WebView.
- **Release build** — NSIS или AppImage с подписью обновлений.
- **Dev build** — `npm run tauri dev` с HMR и инспектором.
