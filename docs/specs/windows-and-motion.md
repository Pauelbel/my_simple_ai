# Окна и движение

## Набор окон

- `main`: главное рабочее пространство.
- Настройки открываются внутри `main`.
- Нельзя создавать дубли `main`; повторный запуск активирует существующее окно.

## Главное окно

- Минимум 900×600, начальный размер 1220×780.
- Последние валидные bounds восстанавливаются внутри доступной области экрана.
- Несохранённая заметка сохраняется до смены файла и закрытия.

## Motion tokens

- Micro: 120–160 ms — hover, press, tooltip.
- Standard: 180–240 ms — панели, selection, theme colors.
- Emphasis: 280–360 ms — появление окна или крупного состояния.
- Основная easing: `cubic-bezier(.2,.8,.2,1)`.
- Scale интерфейсных панелей не меньше 0.985, чтобы избежать «прыжка».
- Layout-анимации используют transform/opacity; дорогие blur/layout пересчёты ограничиваются.

## Reduced motion

При `prefers-reduced-motion: reduce` длительность декоративных переходов близка к нулю.

## Критерии плавности

- Нет полной пересборки DOM при наборе текста.
- Не выполняется сериализация Markdown чаще debounce-интервала или события blur/save для больших документов.
- Цель: 60 fps на Windows 11 при стандартном WebView2.
- Переключение основной панели начинает отрисовку менее чем за 100 ms.
